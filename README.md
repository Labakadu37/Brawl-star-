# JZS Brawl

Client-side mod for Brawl Stars **v69.252** (build 69252).

**V5.5** features:
- Green version badge overlay (`JZS V5.5`)
- **Gold IP:Port display** — reads `/proc/net/tcp` and `/proc/net/tcp6` to
  show the game server address in real time
- Draggable floating mod menu (JZS button) with tabbed UI
- Settings persistence via SharedPreferences
- FPS counter
- Brawl Stars gold/navy theme

The overlay classes ship in an extra DEX. A tiny native library `libjz.so`
is loaded on boot as a signature stamp.

## Layout

```
mod/
├── src/
│   ├── java/com/jzs/brawl/       Java sources (compiled to DEX)
│   │   ├── JZSOverlay.java       badge + gold IP:Port overlay
│   │   ├── JZSMenu.java          floating mod menu with tabs
│   │   ├── JZSConfig.java        SharedPreferences persistence
│   │   ├── JZSTheme.java         Brawl Stars color theme
│   │   └── JZSInit.java          loads libjz.so, inits overlay + menu
│   └── smali/
│       ├── JZSInit.smali         reference smali (regenerated by build)
│       └── patch/                one-line injection for GameApp.smali
└── native/jni/
    ├── libjz.cpp                 native signature stub
    ├── Android.mk
    └── Application.mk

build/
├── build_mod.sh                  full pipeline (decode → inject → sign)
└── inject_overlay.py             idempotent smali injector

docs/
├── SETUP.md                      tooling install
├── BUILD.md                      how the pipeline works step by step
└── INSTALL.md                    installing the resulting APK
```

## Quick build

```bash
export ANDROID_SDK=$HOME/Android/Sdk
export ANDROID_NDK=$ANDROID_SDK/ndk/26.1.10909125
export PATH="$ANDROID_SDK/build-tools/34.0.0:$ANDROID_NDK:$PATH"

./build/build_mod.sh path/to/com.supercell.brawlstars.apk
# → out/jzs-brawl-v5.5.apk
```

See `docs/BUILD.md` for what each step does and `docs/INSTALL.md` for
sideloading the signed APK on your device.

## What the overlay looks like

Top-left of the game screen, above the HUD:

```
┌───────────────────────┐
│  JZS V5.5             │   ← green bold text, black translucent bg
├───────────────────────┤
│  152.67.34.12:9339    │   ← gold (Brawl Stars) text, server IP:port
└───────────────────────┘
        [ JZS ]              ← draggable gold floating button → opens mod menu
```

The IP:Port updates every 2 seconds by reading `/proc/net/tcp`. Shows
"Aucun serveur" when not in a match.
