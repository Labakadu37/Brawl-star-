# JZS Brawl

Client-side mod for Brawl Stars **v69.252** (build 69252) that draws
`JZS V1 (lastest)` as a semi-transparent badge over the game surface.

The overlay is a plain Android `TextView` added to the game's activity
window from a new class `com.jzs.brawl.JZSOverlay` shipped in an extra
`classes3.dex`. A tiny native library `libjz.so` is also loaded on boot to
serve as a signature stamp (`JNI_OnLoad` logs and exports
`Java_com_jzs_brawl_JZSInit_nativeVersion`).

## Layout

```
mod/
├── src/
│   ├── java/com/jzs/brawl/       Java sources (compiled to classes3.dex)
│   │   ├── JZSOverlay.java       adds the TextView to the game window
│   │   └── JZSInit.java          loads libjz.so, calls JZSOverlay.attach
│   └── smali/
│       ├── JZSInit.smali         reference smali (regenerated by build)
│       └── patch/                one-line injection for GameApp.smali
└── native/jni/
    ├── libjz.cpp                 native signature stub
    ├── Android.mk
    └── Application.mk

build/
├── build_mod.sh                  full pipeline (decode → inject → sign)
└── inject_overlay.py             idempotent smali injector

docs/
├── SETUP.md                      tooling install
├── BUILD.md                      how the pipeline works step by step
└── INSTALL.md                    installing the resulting APK
```

## Quick build

```bash
export ANDROID_SDK=$HOME/Android/Sdk
export ANDROID_NDK=$ANDROID_SDK/ndk/26.1.10909125
export PATH="$ANDROID_SDK/build-tools/34.0.0:$ANDROID_NDK:$PATH"

./build/build_mod.sh path/to/com.supercell.brawlstars.apk
# → out/jzs-brawl-v1.apk
```

See `docs/BUILD.md` for what each step does and `docs/INSTALL.md` for
sideloading the signed APK on your device.

## What the overlay looks like

Top-left of the game screen, above the HUD:

```
┌───────────────────────┐
│  JZS V1 (lastest)     │   ← white bold text, black translucent bg
└───────────────────────┘
```

Rendered in the game's own activity window, so it survives orientation
changes and the game's own draw pass without any `SYSTEM_ALERT_WINDOW`
permission.

## Site

`docs/` also holds the English site (`docs/index.html`, same layout as
bsdbrawl.org): hero, download button, features, install guide, FAQ,
Telegram and Brawl Stars club links.

- Hosting: Settings → Pages → *Deploy from a branch* → pick this branch
  and the `/docs` folder. The site goes live at
  `https://labakadu37.github.io/Brawl-star-/`.
- Download button: every button points to
  `releases/latest/download/JZS-Brawl.apk`, so the file downloads
  directly. Create a release (Releases → *Draft a new release*) and attach
  the mod named exactly `JZS-Brawl.apk`. A newer release later updates the
  buttons automatically. To use another host, change `DOWNLOAD_URL` at the
  bottom of `index.html`.
- Images: `docs/img/` (logo, in-game screenshot, gallery crops, install
  steps). Replace a file with one of the same name to swap it.
  `docs/preview.jpg` is the link preview shown on Telegram/Discord.
