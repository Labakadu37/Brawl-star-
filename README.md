# JZS Brawl

Client-side mod for Brawl Stars **v69.252** (build 69252) that draws
`JZS V6.0` as a semi-transparent badge over the game surface.

The overlay is a plain Android `TextView` added to the game's activity
window from a new class `com.jzs.brawl.JZSOverlay` shipped in an extra
`classes3.dex`. A tiny native library `libjz.so` is also loaded on boot to
serve as a signature stamp (`JNI_OnLoad` logs and exports
`Java_com_jzs_brawl_JZSInit_nativeVersion`).

## Nouveautés V6.0

- **Intro animée** (`JZSSplash`) au lancement : le logo « JZS » arrive avec un
  rebond et un dégradé arc-en-ciel qui défile, « BRAWL » tombe lettre par
  lettre, un reflet passe sur le logo, des étincelles partent du centre et une
  barre de chargement se remplit. Touche l'écran pour la passer. Elle ne
  s'affiche qu'une fois par lancement.
- **Notice de bienvenue** (`JZSNotice`) : 6 pages qui expliquent le menu
  (ouvrir, déplacer, langue/config, profil, communauté), avec des points de
  pagination et des transitions glissées. Elle s'affiche au premier lancement
  et peut être rouverte n'importe quand avec `JZSNotice.show(activity)`.
  Passe `NOTICE_VERSION` à la valeur suivante pour que tout le monde la revoie
  après une MAJ.
- Les deux reprennent les couleurs du menu et la police LilitaOne du jeu.
  Le texte est en français ou en anglais selon la langue du téléphone.

### Brancher sur la V5.5

Dans le `JZSInit.install` de la V5.5, ajoute après `JZSModMenu.attach(activity);` :

```java
JZSSplash.show(activity, new Runnable() {
    @Override public void run() { JZSNotice.showIfFirstTime(activity); }
});
```

et copie `JZSUi.java`, `JZSSplash.java` et `JZSNotice.java` à côté.
Pour un bouton « Guide » dans le menu, appelle simplement `JZSNotice.show(activity)`.

## Layout

```
mod/
├── src/
│   ├── java/com/jzs/brawl/       Java sources (compiled to classes3.dex)
│   │   ├── JZSOverlay.java       adds the TextView to the game window
│   │   ├── JZSSplash.java        animated intro on launch
│   │   ├── JZSNotice.java        first-launch welcome guide
│   │   ├── JZSUi.java            shared colors / font / helpers
│   │   └── JZSInit.java          loads libjz.so, attaches overlay, splash, notice
│   └── smali/
│       ├── JZSInit.smali         reference smali (regenerated by build)
│       └── patch/                one-line injection for GameApp.smali
└── native/jni/
    ├── libjz.cpp                 native signature stub
    ├── Android.mk
    └── Application.mk

build/
├── build_mod.sh                  full pipeline (decode → inject → sign)
└── inject_overlay.py             idempotent smali injector

docs/
├── SETUP.md                      tooling install
├── BUILD.md                      how the pipeline works step by step
└── INSTALL.md                    installing the resulting APK
```

## Quick build

```bash
export ANDROID_SDK=$HOME/Android/Sdk
export ANDROID_NDK=$ANDROID_SDK/ndk/26.1.10909125
export PATH="$ANDROID_SDK/build-tools/34.0.0:$ANDROID_NDK:$PATH"

./build/build_mod.sh path/to/com.supercell.brawlstars.apk
# → out/jzs-brawl-v6.apk
```

See `docs/BUILD.md` for what each step does and `docs/INSTALL.md` for
sideloading the signed APK on your device.

## What the overlay looks like

Top-left of the game screen, above the HUD:

```
┌───────────────────────┐
│  JZS V6.0     │   ← white bold text, black translucent bg
└───────────────────────┘
```

Rendered in the game's own activity window, so it survives orientation
changes and the game's own draw pass without any `SYSTEM_ALERT_WINDOW`
permission.
