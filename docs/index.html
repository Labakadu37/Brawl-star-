Fonctions

JZS Brawl reste volontairement minimal : il ajoute une signature visuelle sans toucher au gameplay ni au réseau.

🏷️

Badge JZS

« JZS V1 (lastest) » en blanc sur fond noir translucide, en haut à gauche, au-dessus du HUD.

🔄

Stable à la rotation

Le badge vit dans la fenêtre de l'activité du jeu : il survit aux changements d'orientation et aux redessins.

🔓

Aucune permission

Pas besoin de SYSTEM_ALERT_WINDOW ni d'accès spécial.

⚙️

Lib native libjz.so

Petite bibliothèque JNI de signature, optionnelle : le mod marche même sans elle.

🛠️

Build en 1 commande

build_mod.sh décode, injecte, reconstruit et signe l'APK automatiquement.

🛡️

Zéro avantage

Aucune modif du protocole réseau ni des stats : c'est purement visuel.

Avantages

  • Code open source, tout est lisible
  • Très léger, aucun impact sur les perfs
  • Pas de permissions supplémentaires
  • Build reproductible depuis ton propre APK

Inconvénients

  • Il faut rebuild à chaque mise à jour du jeu
  • Incompatible avec l'install Play Store (signature différente)
  • Android uniquement
  • Les mods clients restent contraires aux CGU de Supercell

Installation

Aucun APK n'est hébergé ici : tu construis le mod à partir de ton propre fichier Brawl Stars, puis tu l'installes.

  1. Installe les outils : JDK 17, Android SDK build-tools 34, NDK 26, apktool, baksmali. Détails dans SETUP.md.
  2. Clone le repo 
    git clone https://github.com/Labakadu37/Brawl-star-
cd Brawl-star-
  3. Configure l'environnement 
    export ANDROID_SDK=$HOME/Android/Sdk
export ANDROID_NDK=$ANDROID_SDK/ndk/26.1.10909125
export PATH="$ANDROID_SDK/build-tools/34.0.0:$ANDROID_NDK:$PATH"
  4. Lance le build avec l'APK de base de Brawl Stars v69.252 
    ./build/build_mod.sh path/to/com.supercell.brawlstars.apk
# → out/jzs-brawl-v1.apk
    Le détail de chaque étape est dans BUILD.md.
  1. Désinstalle la version Play Store de Brawl Stars (sinon la signature ne correspond pas).
  2. Copie le dossier XAPK sur ton téléphone.
  3. Remplace com.supercell.brawlstars.apk par out/jzs-brawl-v1.apk en gardant le même nom.
  4. Ouvre le .xapk avec SAI (Split APKs Installer) et appuie sur Installer.
  1. Désinstalle la version Play Store et active le débogage USB.
  2. Installe tous les splits ensemble 
    adb install-multiple \
    out/jzs-brawl-v1.apk \
    xapk/config.armeabi_v7a.apk \
    xapk/config.en.apk \
    xapk/config.mdpi.apk \
    xapk/install_time_asset_pack.apk
  3. Vérifie que le mod démarre 
    adb logcat -s JZS
    Le badge doit apparaître en haut à gauche. Problèmes ? Voir INSTALL.md.

FAQ

JZS Brawl donne-t-il un avantage en jeu ?

Non. Le mod ajoute seulement un badge visuel. Il ne touche ni au réseau, ni aux stats, ni au comportement des brawlers.

Pourquoi il n'y a pas de bouton de téléchargement d'APK ?

Parce que l'APK contient le code et les assets de Supercell, qu'on n'a pas le droit de redistribuer. Tu construis le mod toi-même à partir de ton propre fichier : c'est aussi plus sûr qu'un APK téléchargé sur un site inconnu.

Est-ce que je risque un ban ?

Tout mod client est contraire aux conditions d'utilisation de Supercell. JZS Brawl est purement cosmétique, mais il n'y a aucune garantie : utilise un compte secondaire si tu veux zéro risque.

Ça marche sur iOS ou PC ?

Android uniquement. Sur PC, tu peux passer par un émulateur Android (et installer via adb).

Le jeu crash au lancement avec ClassNotFoundException

Le smali du mod n'a pas été intégré. Relance le build et vérifie que classes3.dex est bien présent dans l'APK final.

Que faire quand Brawl Stars se met à jour ?

Récupère le nouvel APK de base et relance build_mod.sh. Si la structure de GameApp.smali change, l'injecteur devra peut-être être adapté.
