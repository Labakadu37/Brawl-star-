Comment installer JZS Brawl sur Android

Installer JZS Brawl sur Android c'est super simple, ça prend quelques étapes. Si c'est ta première fois, suis le guide ci-dessous :

Guide étape par étape

  1. Télécharge l'APK de JZS Brawl avec le bouton Télécharger de cette page.
  2. Ouvre le gestionnaire de fichiers ou ton navigateur, va dans le dossier Téléchargements et appuie sur l'APK de JZS Brawl.
  3. Si c'est la première fois, ton téléphone affiche un message qui dit que l'installation d'applis inconnues n'est pas autorisée.
  4. Appuie sur Paramètres et active « Autoriser cette source ».
  5. Reviens en arrière, la fenêtre d'installation s'ouvre. Appuie sur Installer et attends quelques secondes.
  6. C'est installé ! Ouvre JZS Brawl et amuse-toi bien.

Comment jouer à JZS Brawl sur PC

Pour jouer à JZS Brawl sur PC, il te faut l'APK et un émulateur Android comme BlueStacks. Une fois que tu as les deux, suis ces étapes :

Première méthode

  1. Télécharge l'APK de JZS Brawl sur ton ordinateur.
  2. Télécharge et installe l'émulateur BlueStacks sur ton PC.
  3. Lance BlueStacks.
  4. Dans la barre latérale de BlueStacks, clique sur le bouton « Installer APK ».
  5. Une fenêtre s'ouvre : va dans le dossier où se trouve l'APK.
  6. Sélectionne l'APK et clique sur Ouvrir.
  7. BlueStacks installe le jeu.
  8. Quand c'est fini, l'icône de JZS Brawl apparaît sur l'accueil de BlueStacks. Clique dessus pour jouer.

Deuxième méthode

Encore plus rapide : après avoir lancé BlueStacks (étapes 1 à 3 au-dessus), fais simplement glisser l'APK dans la fenêtre de BlueStacks. L'installation démarre toute seule. Une fois terminée, tu peux ouvrir le jeu et jouer.

Comment te connecter avec ton Supercell ID

Pour jouer à JZS Brawl avec ton compte, connecte-toi avec ton Supercell ID :

  1. Installe et ouvre JZS Brawl.
  2. Pendant le tutoriel, appuie sur le bouton Supercell ID en haut à gauche de l'écran.
  3. Entre l'adresse e-mail liée à ton Supercell ID et appuie sur Suivant.
  4. Entre le code de vérification reçu par e-mail et appuie sur Suivant.
  5. Ton compte Brawl Stars s'affiche. Appuie sur Terminé.
  6. C'est bon ! Ton compte est chargé dans JZS Brawl.
